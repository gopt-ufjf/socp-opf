# SOCP-Based Optimal Power Flow

This repository contains an implementation of an Optimal Power Flow (OPF) model using Second-Order Cone Programming (SOCP) techniques. 

The computational model implemented in this repository is based on the methodology presented in the following scientific publication:

> Jabr, Rabih A.  
> *"Outer approximation method for discrete AC optimal power flow."*  
> IEEE Transactions on Power Systems, vol. 40, no. 2, 2024, pp. 1943–1954.
